# 결정석 장부

메이플스토리 본캐·부캐의 주간 보스를 체크하고 결정석 판매 수익을 정산하는 웹앱입니다.
서버 없이 `index.html` 하나로 동작하며, 기록은 브라우저(`localStorage`)에만 저장됩니다.

## 기능

- **대시보드**: 캐릭터별 보스 체크리스트(줄을 누르면 체크), 클리어 시각 기록, 보스 소요 시간·남은 시간, 전부 클리어 / 체크 해제, 카드 접기
- **보스 편집**: 난이도 버튼으로 보스 선택(캐릭터당 주간 12마리), 파티 인원, 하위 주보·노말 주보·검밑솔 세트, 다른 캐릭터 따라하기
- **자동 정산**: 파티 보스는 가격 ÷ 인원, 캐릭터당 12개·월드당 90개 판매 한도를 비싼 결정석부터 적용
- **요약**: 이번 주 확정/예상 수익, 90개 한도 게이지, 이번 달 누적 수익, 주간 목표
- **정산표·주간 기록**: 캐릭터별 정산, 최근 12주 그래프(평균·최고), 목요일 리셋 때 자동 기록
- **지난 주 기록 고치기**: 체크를 깜빡해도 최근 4주까지 보스별 체크를 고치면 그 주 가격 기준으로 다시 정산 (리셋 후 미체크 보스 안내)
- **도핑 묶음 계산**: 보스별 걸린 시간(분)을 적어 두면 **도핑 묶음** 버튼을 누를 때마다 그때 남은 솔로 주간 보스를 버프 시간(기본 30분) 안에 들어가게 묶어 도핑 횟수를 최소화(파티·월간 보스 제외). 묶음 머리줄에 시간·메소·큐브 합계, 누르면 묶음 전체 체크/해제
- **큐브**: 보스별 확정 메멘토 큐브(골드·실버)를 메소 옆에 아이콘으로 표시하고 이번 주 확정/예정 개수 집계, 설정에서 큐브 보상표 수정
- **주급**: 주간 확정 수익을 주급으로 보고 지난주 대비 인상/삭감률, 연속 인상, 커리어 하이, 4주 성장률 표시
- **캐릭터 메모**: 카드의 ✎로 짧은 메모(최대 30자)
- **놓친 주급**: 고른 보스를 다 못 잡은 만큼 놓친 주급을 주마다 계산하고 누적 표시 (그래프의 흐린 부분)
- **캐릭터 순서 바꾸기**: 끌어서 놓기·↑↓·빠른 정렬(본캐 먼저, 예상 수익 순, 이름순)
- **리셋 전 알림**: 리셋 24시간 전부터 남은 보스와 놓칠 주급 안내
- **주급 명세서 복사**: 이번 주 결과를 텍스트로 복사해 공유
- **테마**: 자동 / 라이트 / 다크 전환 버튼
- **설정**: 결정석 가격표 수정, 이번 주 체크 초기화, JSON 파일 내보내기(`결정석장부_날짜_캐릭터이름.json`)/가져오기, 백업 코드 복사/불러오기

## 규칙 (2026-09-17 패치 기준)

- 주간 리셋: 매주 목요일 00:00 (KST) / 월간 보스(검은 마법사): 매월 1일
- 판매 한도: 캐릭터당 주간 12개, 월드당 주간 90개 (일일 보스는 다루지 않음)
- 기본 가격은 패치마다 바뀔 수 있으니 설정 → 결정석 가격표에서 고쳐 쓰세요.

## 실행

`index.html`을 브라우저로 열면 됩니다. 파일을 바로 열면 일부 환경에서 저장이 막힐 수 있으니, 아래처럼 로컬 서버로 여는 것을 권장합니다.

```bash
python -m http.server 8000
```

그다음 `http://localhost:8000` 에 접속합니다.

## GitHub Pages 배포

1. 이 폴더를 GitHub 저장소로 올립니다 (`index.html`이 저장소 최상위에 있어야 합니다).
2. 저장소 **Settings → Pages**에서 Source를 `Deploy from a branch`, 브랜치를 `main` / `/ (root)`로 지정합니다.
3. 잠시 후 `https://<사용자명>.github.io/<저장소명>/` 에서 열립니다.

데이터는 접속한 브라우저에만 저장되므로, 기기를 옮길 때는 설정의 **JSON 파일로 내보내기 → 가져오기**를 쓰세요.
